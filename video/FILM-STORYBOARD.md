## 02 问题｜0:10–0:26

**核心文案**
> HMCL 很完整，但它没有给第三方留任何接口。

**画面（不是三张卡）**

一个横向展开的 2.5D 空间，镜头从左向右缓慢横移，穿过三个“空插槽”：

1. **第一个空插槽**
   - 一个 HMCL 窗口轮廓，侧边伸出三个空的接口槽；
   - 插头靠近，接触瞬间弹开，出现细小的红色电弧；
   - 大字：「没有插件接口」。

2. **第二个空插槽**
   - 浮空的脚本图标、API 图标尝试接入，全部穿过窗口，落空；
   - 大字：「没有脚本 / 官方 API」。

3. **第三个空插槽**
   - HMCL 窗口下方没有 Fabric 层，Fabric mod 图标无处落脚；
   - 大字：「不是 Fabric 宿主」；
   - 下方小字：「只能改源码，每次升级都要重新合并」。

**结尾**
- 镜头推近到 HMCL 窗口内部，画面逐渐白化；
- 一行字从白场中浮出：

> 所以，FLFHMCL 先给它一个 Fabric 运行时。

**运镜**
- 全程横移（tracking shot），不是卡片切换；
- 每个空插槽经过时，前景插头产生视差；
- 结尾推轨加速，配合音乐渐强进入下一段。

## 运镜与节奏原则

- 场景切换：9.8 / 25.8 / 43.8 / 62.0 / 80.2 / 96.0 / 112.0 / 126.0 / 138.0 秒；
- 每个场景至少一个主动运镜：推、拉、横移、升降、环绕、轻微手持；
- 卡片只保留在“启动器功能说明”一小段，其余用空间、层次、光线和文字排版；
- 节拍点用于：镜头落位、文字出现、光线脉冲；
- 音乐从 0 秒开始，开场渐强对应启幕推近。
